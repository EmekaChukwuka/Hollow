How to Use Hollow

1. Create a Project

Click "New Project" and give it a name.

2. Add an Endpoint

Click "New Endpoint" and configure:

  • Method — GET, POST, PUT, DELETE
  • Path — e.g., /users
  • Mode — Static (mock) or Dynamic (data storage)

3. Use Your API

Your API URL is: https://hollow-3mbn.onrender.com/{projectId}/{path}

Example with cURL: curl https://hollow-3mbn.onrender.com/proj_abc123/users

💡 Tip: Share your API URL with your frontend team. They can start building immediately!
