Introduction

Learn what Hollow is and how it can help you build apps faster.

What is Hollow?

Hollow is a backend-as-a-service designed specifically for frontend developers. It gives you a working backend in minutes — without writing a single line of server code.

Why Hollow?

As a frontend developer, you shouldn't have to learn Express, set up a database, write authentication, or deploy to a server just to store some data.

Hollow handles all of that for you. Define your endpoints, configure your schema, and get a live API URL you can use immediately.

💡 Perfect for: Solo developers, indie hackers, frontend engineers, and anyone who wants to ship fast without building a backend.

Quick Example

Create a project, add a dynamic endpoint, and start using it in 5 minutes.

// 1. Create a project POST /api/projects { "name": "My App" } // 2. Add an endpoint POST /api/projects/:id/endpoints { "method": "GET", "path": "/users", "mode": "dynamic", "schema": { "fields": { "name": { "type": "string", "required": true }, "email": { "type": "email", "required": true } } } } // 3. Use it in your frontend fetch('https://hollow.dev/proj_abc/users') .then(res => res.json()) .then(data => console.log(data));

Features at a Glance

🚀 Instant Setup

Define endpoints in seconds. No configuration files, no Docker, no boilerplate.

📦 Full CRUD

GET, POST, PUT, PATCH, DELETE. Store and retrieve data immediately.

🔒 Built-in Validation

Define schemas and Hollow validates incoming data automatically.

🔑 API Key Management

Secure your endpoints with API keys. Toggle them on and off per project.

📊 Request Logs

See every request to your API. Debug faster.

🎯 Multiple Scenarios

Configure success, error, unauthorized, and other responses (static mode).
